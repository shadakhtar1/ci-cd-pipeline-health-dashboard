===========================================================
PROJECT
===========================================================

Project Name

CI/CD Pipeline Health Dashboard

Goal

Develop a production-quality web application that monitors CI/CD pipeline executions from GitHub Actions (preferred) or Jenkins.

The application should collect build information using APIs, store the data, visualize metrics, provide alerts, and be fully containerized.

===========================================================
ASSIGNMENT REQUIREMENTS
===========================================================

The dashboard must

• Collect pipeline execution information
    - Build Number
    - Pipeline Name
    - Status
    - Success/Failure
    - Duration
    - Branch
    - Commit ID
    - Commit Message
    - Triggered By
    - Started Time
    - Completed Time

• Show real-time metrics

    - Success Rate
    - Failure Rate
    - Average Build Time
    - Last Build Status
    - Total Builds
    - Recent Builds

• Display

    - Latest builds
    - Build history
    - Logs
    - Pipeline status

• Send Email alerts when pipeline fails

• Provide a simple frontend dashboard
